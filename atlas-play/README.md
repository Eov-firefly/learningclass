# Atlas Play · 指尖环游

原创地理定位 Web 游戏原型。灵感来自地图标点游戏，使用独立品牌、中文界面、自编地点说明及自建小型题库，与 MapTap 无关联。

## 启动

需要 Node.js 20.19+ 或 22.12+（当前验证环境为 Node.js 24）。

```bash
npm ci
npm run dev
```

开发服务默认监听端口 5173；可通过 `npm run dev -- --port 其他端口` 修改。构建和本地预览：

```bash
npm run build
npm run preview
```

构建结果在 `dist/`，可部署到静态网站托管平台。所有运行资源随构建打包，不依赖在线地图 API、远程图片或在线字体。不需要 API Key。

## 已实现

- 真实世界陆地轮廓的 Three.js 三维地球，拖动旋转、滚轮/双指缩放、点击选点。
- 落点二次确认，目标位置、猜测位置及球面连线揭晓。
- 30个城市与地标，附原创中文知识卡片。
- 按浏览器本地日期确定的每日五题；每日题目由固定种子生成。
- 按距离计分、22公里内满分、五题权重1/1/2/3/3，总分1000。
- 本站原创平方衰减评分，不是 MapTap 精确计分复刻，不含国家/大洲奖励。
- 城市、地标、综合三种随机练习，不覆盖每日挑战记录。
- 单题提交即保存、中断恢复、成绩历史与连续完成天数。
- 纯文字成绩复制；剪贴板权限不足时弹出手动复制框。
- 桌面/手机布局，键盘可操作控件及经纬度输入。
- WebGL不可用时显示说明，仍可通过经纬度输入完成游戏。
- 支持减少动态效果的系统偏好。

## 规则

在地球上点击猜测位置，按“确认我的落点”提交。每题提交后不能重答；揭晓后点击继续。地球上的浅绿色标记表示猜测，白色标记表示目标。完成后可逐条回顾地点。

设距离为 `d`（公里），单题分数为：

```text
round(100 × max(0, 1 − max(0, d − 22) / 19993)²)
```

距离使用半径6371公里的球面大圆距离。每日题目以页面加载时的本地日期为准，跨午夜后刷新可进入新的一天。

## 测试

```bash
npm test
# 首次需安装浏览器：
npx playwright install chromium
npm run test:e2e
```

已有系统 Chromium 的 Linux 环境可执行：

```bash
CHROMIUM_PATH=/usr/bin/chromium npm run test:e2e
```

单元测试覆盖球面距离、日期变更、评分边界与单调性、每日选题、分类题库、权重、存档校验及连续天数。浏览器测试覆盖完整五题、剪贴板、历史记录、进度恢复、练习隔离、移动端旋转选点、错误存档和WebGL降级。

## 数据来源与边界

地球轮廓使用 `world-atlas` 提供的 Natural Earth 概化陆地数据，经 `topojson-client` 转换后在本地生成纹理；地球无政治国界。数据来源：[world-atlas](https://github.com/topojson/world-atlas)、[Natural Earth](https://www.naturalearthdata.com/about/terms-of-use/)。地点坐标为近似参考点，知识说明为自编简述。本项目仅供娱乐与原型验证，不用于导航或边界判定。

## 当前限制与后续方向

本版为独立静态前端原型：没有账号、云同步、可信排行榜、订阅、真实多人对战或内容管理后台。成绩保存在当前浏览器，可被本机修改；清除存储会删除成绩。当前30题适合功能验证，正式运营需要扩大、审核和版本化题库。

建议下一阶段：数据驱动的难度分层、内容后台、账号与云存档、服务端计分校验，然后再做异步对战与会员。不要使用本地存档作为竞技可信数据源。
